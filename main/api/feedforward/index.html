Feed-forward networks (depthcharge.feedforward)

FeedForward(in_features, out_features, layers, dropout=0, activation=torch.nn.LeakyReLU(), append=None)

Bases: Module

Create a feed forward neural network.

PARAMETER DESCRIPTION
in_features

The input dimensionality.

TYPE: int

out_features

The output dimensionality.

TYPE: int

layers

If an int, layer sizes are linearly interpolated between the input and output dimensions using this number of layers. Otherwise, each element specifies the size of a layer.

TYPE: int or tuple of int.

dropout

If greater than zero, add dropout layers with the specified probability.

TYPE: float DEFAULT: 0

activation

The activation function to place between layers.

TYPE: Module DEFAULT: LeakyReLU()

append

A final layer to append, such as a sigmoid or tanh.

TYPE: Module or None DEFAULT: None

Methods:

forward(X)

The forward pass.

PARAMETER DESCRIPTION
X

The input tensor.

TYPE: torch.Tensor of shape (..., in_features)

RETURNS DESCRIPTION
torch.Tensor of shape (..., out_features)

The output tensor.
